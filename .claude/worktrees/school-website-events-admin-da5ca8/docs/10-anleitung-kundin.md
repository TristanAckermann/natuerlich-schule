# Anleitung: Veranstaltungen auf der Webseite pflegen

Diese Anleitung richtet sich an die Person, die die Veranstaltungen auf der Webseite
pflegt. Es braucht keine technischen Vorkenntnisse.

---

## Anmelden

1. Öffnen Sie im Browser: **`www.ihre-domain.ch/admin`**
2. Geben Sie Ihre E-Mail-Adresse und Ihr Passwort ein.
3. Sie sehen jetzt die Liste aller Veranstaltungen.

**Passwort vergessen?** Klicken Sie auf der Anmeldeseite auf *Passwort vergessen*. Sie
bekommen eine E-Mail mit einem Link, über den Sie ein neues Passwort setzen können.

> Tipp: Legen Sie sich ein Lesezeichen auf die Adresse `/admin`.

---

## Die Übersicht verstehen

In der Liste steht bei jeder Veranstaltung ein farbiger Hinweis:

| Hinweis | Bedeutung |
|---|---|
| **Veröffentlicht** | Die Veranstaltung ist auf der Webseite für alle sichtbar. |
| **Entwurf** | Nur Sie sehen sie. Für Besucher der Webseite existiert sie nicht. |

Neue Veranstaltungen sind immer zuerst ein **Entwurf**. So können Sie in Ruhe arbeiten,
ohne dass etwas Halbfertiges online geht.

---

## Eine neue Veranstaltung anlegen

1. Klicken Sie oben rechts auf **Neue Veranstaltung**.
2. Füllen Sie die Felder aus:

| Feld | Was hineingehört |
|---|---|
| **Titel** | Der Name der Veranstaltung, z.B. „Sommerfest 2026". |
| **URL-Kürzel** | Wird automatisch aus dem Titel gebildet. Sie müssen hier normalerweise nichts tun. Es ist der Teil, der später in der Internetadresse steht. |
| **Beginn** | Datum und Uhrzeit. |
| **Ende** | Optional. Nur ausfüllen, wenn es sinnvoll ist. |
| **Ganztägig** | Ankreuzen, wenn keine Uhrzeit angezeigt werden soll. |
| **Ort** | z.B. „Turnhalle" oder „Schulhausplatz". |
| **Kurzbeschreibung** | Ein bis zwei Sätze. Dieser Text erscheint in der Übersicht und in der Google-Suche. |
| **Beschreibung** | Der ausführliche Text. Hier dürfen es gern mehrere Absätze sein. |
| **Bild** | Ein Foto zur Veranstaltung. Siehe unten. |
| **Bildbeschreibung** | Kurz beschreiben, was auf dem Bild zu sehen ist. Wichtig für blinde Menschen und für Google. |

3. Klicken Sie auf **Speichern**. Die Veranstaltung ist jetzt ein Entwurf.
4. Klicken Sie auf **Vorschau**, um zu sehen, wie sie aussehen wird.
5. Wenn alles passt: Status auf **Veröffentlicht** stellen und nochmals **Speichern**.

---

## Ein Bild hinzufügen

1. Im Feld **Bild** auf *Datei wählen* klicken oder das Foto einfach ins Feld ziehen.
2. Warten, bis die Vorschau erscheint.
3. **Bildbeschreibung** ausfüllen.

**Das sollten Sie beachten:** Die Webseite verkleinert Fotos **nicht** automatisch – ein
Foto direkt von der Handykamera ist oft mehrere Megabyte gross und macht die Seite
langsam. Bringen Sie das Bild vorher auf etwa 1600 Pixel Breite:

- **Am Handy:** Beim Teilen/Versenden „Mittlere Grösse" statt „Originalgrösse" wählen.
- **Am Mac:** Vorschau öffnen → Werkzeuge → Grösse korrigieren.
- **Unter Windows:** Foto mit der rechten Maustaste → Öffnen mit „Fotos" → Grösse ändern.

Querformat sieht besser aus als Hochformat. Und bei Fotos von Kindern muss die
Einwilligung der Eltern vorliegen.

---

## Eine Veranstaltung ändern

1. In der Liste auf die Veranstaltung klicken.
2. Ändern, was Sie ändern wollen.
3. **Speichern**.

Die Änderung ist innerhalb weniger Minuten auf der Webseite sichtbar. Wenn Sie sofort
nachschauen und noch das Alte sehen: kurz warten und die Seite neu laden.

---

## Eine Veranstaltung von der Webseite nehmen

Sie haben zwei Möglichkeiten:

**Auf Entwurf zurückstellen** – die Veranstaltung verschwindet von der Webseite, bleibt
Ihnen aber erhalten. Sie können sie jederzeit wieder veröffentlichen. **Das ist meistens
die bessere Wahl.**

**Löschen** – die Veranstaltung ist endgültig weg und kann nicht wiederhergestellt werden.
Sie werden vorher noch einmal gefragt.

> Vergangene Veranstaltungen müssen Sie **nicht** löschen. Die Webseite sortiert
> automatisch: Kommende Termine stehen oben, vergangene rutschen nach unten.

---

## Den Einleitungstext der Seite ändern

Über der Liste der Veranstaltungen steht auf der Webseite ein Titel und ein kurzer Text.
Den ändern Sie so:

1. Im Menü auf **Seitentext** klicken.
2. Titel und Text anpassen.
3. **Speichern**.

---

## Text gestalten

Im Feld **Beschreibung** können Sie einfache Auszeichnungen verwenden:

| Sie schreiben | Ergebnis |
|---|---|
| `**wichtig**` | **wichtig** |
| `*betont*` | *betont* |
| `- Punkt eins`<br>`- Punkt zwei` | Aufzählung |
| `[Anmeldung](https://…)` | Ein Link |

Eine leere Zeile zwischen zwei Absätzen erzeugt einen Absatz. Mehr braucht es nicht.

---

## Häufige Fragen

**Ich habe etwas gespeichert, sehe es aber nicht auf der Webseite.**
Drei mögliche Gründe: Der Status steht noch auf *Entwurf*. Oder es sind noch keine fünf
Minuten vergangen. Oder Ihr Browser zeigt eine gespeicherte Version – laden Sie die Seite
mit `Ctrl`+`Shift`+`R` (Windows) bzw. `Cmd`+`Shift`+`R` (Mac) neu.

**Ich habe aus Versehen etwas gelöscht.**
Melden Sie sich möglichst bald – es gibt tägliche Sicherungen, aber sie werden nur eine
Woche aufbewahrt.

**Kann ich die anderen Seiten auch ändern?**
Nein, „Über uns", „Konzept" und die übrigen Seiten ändern sich nur selten. Melden Sie
Änderungswünsche einfach per E-Mail.

**Kann ich das auch am Tablet machen?**
Ja. Die Oberfläche funktioniert auf Tablet und Handy.

**Ich komme nicht mehr rein.**
Zuerst *Passwort vergessen* versuchen. Wenn die E-Mail nicht ankommt, melden Sie sich.
